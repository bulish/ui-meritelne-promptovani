## Summary

This thesis details the implementation of selected client-side functionalities for Mendel University’s new accreditation application, replacing fragmented manual workflows with a unified, web-based digital environment. Built using the Vue.js framework and JavaScript, the project focuses on developing core modules such as Form A-I, Form B-I, a dedicated academic publications section within user profiles, and an administration sub-application.

The application integrates directly with the University Information System (UIS) to automate data retrieval, eliminate redundant entries, and ensure data integrity. Furthermore, it features a centralized approval engine and dynamic status-based permissions matrix that controls user access, handles multi-tier workflow transitions, and records a transparent audit trail of comments and revisions. Rigorous testing, including end-to-end simulations using Cypress, was conducted to guarantee system stability and reliability under real-world operational conditions.
