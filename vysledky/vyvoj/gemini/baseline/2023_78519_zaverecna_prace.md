This study explores and compares the effectiveness of a fuzzy-logic-based expert system and traditional machine learning approaches, specifically content-based filtering, for movie recommendation. Utilizing a quantitative research design and a dataset containing over 700,000 observations, the research evaluates both models using metrics such as accuracy, F1 score, precision, recall, and confusion matrices.

The fuzzy logic expert model incorporates user preferences, linguistic variables, and fuzzy inference rules to manage uncertainty and imprecision. Conversely, the content-based machine learning model employs text vectorization (Bag-of-Words), Porter stemming, and cosine similarity to match movie attributes and recommend relevant titles.

The performance evaluation demonstrates that while the fuzzy logic model achieves high overall accuracy (0.98), changing evaluation thresholds significantly shifts system results. Although fuzzy models excel at handling subjective user preferences and transparency, the discussion and results indicate that content-based machine learning models offer a more favorable balance when considering a broader range of performance metrics like precision and recall for practical recommendation tasks.
