## Goal

The principal goal of this thesis is to implement specific client-side components of the Mendel University accreditation system by developing an easy-to-navigate web interface capable of handling complex administrative requirements using Vue.js and JavaScript.

## Methods

The application was built using Vue.js, JavaScript, and Vuetify, following Figma specifications and utilizing Pinia stores for state management. Development utilized the Scrumban methodology, GitLab for version control, and Cypress for automated end-to-end testing.

## Main results

The project successfully implemented core modules including Form A-I, Form B-I, a research publications section, an administration sub-application, and a centralized approval engine that tracks file workflows and dynamically enforces role-based access control and form statuses.

## Conclusions

The new accreditation application successfully replaces outdated manual workflows with a secure, centralized digital environment that eliminates manual entry, improves data integrity, provides real-time transparency, and establishes a scalable foundation for future university expansions.
