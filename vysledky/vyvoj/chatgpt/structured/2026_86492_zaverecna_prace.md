Goal: The thesis aimed to implement selected client-side functionalities of Mendel University in Brno’s new Accreditation application, replacing fragmented manual workflows with a centralized web-based system. The objectives included developing Forms A-I and B-I, a publications section, approval and status management, and an administration sub-application.     2026_86492_zaverecna_prace
Methods: The implementation translated high-fidelity Figma designs into a Vue.js application integrated with backend services. It used modular, component-based architecture, Pinia stores, composables, Vuetify, and JavaScript. The implementation included data synchronization, role-based permissions, validation, workflow logic, centralized approval handling, and administration components.     2026_86492_zaverecna_prace
Main results: Forms A-I and B-I were implemented with reactive interfaces, validation, persistence, workflow actions, and role-dependent access. The approval engine centralized workflow operations and synchronized form status with the client interface. The administration module provided reusable components for managing institutional data while preserving closed-file integrity. Testing combined continuous internal testing, customer testing, final pre-launch testing, and automated Cypress end-to-end scenarios covering A-I, B-I, and accreditation-record creation. All critical bugs identified during final testing were resolved.     2026_86492_zaverecna_prace     2026_86492_zaverecna_prace
