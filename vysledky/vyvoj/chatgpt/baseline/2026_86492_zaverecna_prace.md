Summary
This thesis presents the implementation of selected client-side functionalities for Mendel University in Brno’s digital accreditation application. The project addresses shortcomings in the previous process, which depended on fragmented Word and Excel documents, repeated data entry, and email-based approval, causing inefficiency and risks of inconsistent information. The implemented solution uses Vue.js, JavaScript, Pinia, and related web technologies to create a centralized interface connected to university data sources. Core functionality includes Forms A-I and B-I, which combine automatically retrieved institutional information with validated user input. The application also introduces role- and status-based access control, allowing permissions and available actions to change according to a document’s position in the approval workflow. A centralized approval engine manages submissions, approvals, rework, communication, and finalization while maintaining an audit trail. An administration sub-application provides reusable components for managing institutional data and preserves historical accuracy for closed accreditation files. Testing combined continuous internal testing, user testing, and automated Cypress end-to-end scenarios covering form editing, data persistence, and accreditation-file creation.
