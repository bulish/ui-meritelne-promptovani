This thesis focuses on the implementation of selected client-side functional­ ities for the Accreditation application at Mendel University in Brno. The work addresses the limitations of the previous manual accreditation process, which relied on static documents and fragmented spreadsheets. By transitioning to a centralized digital ecosystem, the project aims to improve operational trans­ parency and ensure the accuracy of data throughout the accreditation lifecycle. The development was carried out using Vue.js and JavaScript to create a respons­ ive and user-friendly interface. Primary attention was given to the implementa­ tion of the A-I and B-I accreditation forms, as these components are essential for gathering and validating academic data. The scope of the work also includes the design of an automated approval engine, administration sub-application, and a centralized user profile for publication management. A key feature of the solu­ tion is the integration with the University Information System, which allows for the automatic retrieval of verified institutional records and eliminates the need for repetitive data entry. The reliability of the application was verified through a multi-staged testing strategy. This involved internal developer reviews, the distribution of a Minimum Viable Product for early stakeholder feedback, and a final period of customer validation before the official launch. Additionally, automated end-to-end testing was performed using the Cypress framework to ensure that core user journeys remained stable across the platform. The final results demonstrate a secure and extensible system that significantly reduces administrative overhead. While current modules utilize JavaScript, the project architecture is designed to support a future migration to TypeScript to ensure long-term maintainability and cohesion with the SmartMENDELU ecosystem of applications.
