This bachelor thesis is the creation of practical laboratory exercises focused on im- plementing wireless networks using topics aligned with the CCNP ENWLSI certifi- cation objectives. The exercises cover topics such as access point operating modes, FlexConnect, and wireless security. Each lab has a goal, theoretical background, defined topology and equipment, configuration steps, and a summary. The result of this thesis is a set of structured lab exercises that support practical learning of wireless networks.
